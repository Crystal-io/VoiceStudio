## 1. Коротко

VoiceStage — веб-приложение для вокальной студии (1 директор, ~5 педагогов,
~30 детей), которое ставится на телефон как обычное приложение. Оно заменяет
тетрадь и чат: **расписание** индивидуальных и групповых занятий, **карточки
учеников** с контактами родителей, **посещаемость** в одно касание,
**касса** (прайс и доли педагогов, приём оплаты, долги и авансы детей),
**загрузка кабинетов** с бронированием и табло для холла, **отчёты** для
директора. Суммы — в евро.

## 2. Роли и доступ

| Роль | Кто это | Главное |
|---|---|---|
| **Директор** | руководитель студии (их может быть несколько); он же ведёт кассу | видит и меняет всё: педагоги и директора, кабинеты, все занятия, прайс и доли педагогов, касса и оплаты, отчёты, часы работы и праздники; может и сам вести занятия |
| **Педагог** | преподаватель | ведёт свои занятия и посещаемость, заводит учеников, комплектует группы, бронирует кабинеты; принимает оплату у детей своих занятий и видит свою кассу |

- **Вход** — без пароля: «Продолжить с Google» или одноразовый код на почту.
- **Только по приглашению**: директор вписывает человека (имя + почта +
  роль «Педагог» или «Директор») в «Студия» → «Педагоги»; тот входит с этой почтой — и
  сразу попадает в студию. Приглашение действует 30 дней (можно продлить).
  Чужая почта доступа к данным не получает. У Gmail точки и «+хвост» в
  адресе не важны: ivan.petrov@gmail.com = ivanpetrov@gmail.com.
- **Отключить доступ** может только директор: отключённый больше не видит
  ничего (даже на уже открытом телефоне — при следующем открытии приложения
  экран «Доступ отключён»). Роль и доступ себе не поменять, а в студии
  всегда остаётся хотя бы один действующий директор.
- **Установка на телефон**: открыть адрес приложения в браузере → «Добавить
  на главный экран» (iPhone: «Поделиться» → «На экран „Домой“»). Обновляется
  само; если после обновления что-то выглядит по-старому — закрыть
  приложение и открыть снова.

## 3. Карта разделов

**Нижнее меню директора:** Главная · Расписание · Студия · Касса

| Раздел | Директор | Педагог | Что внутри |
|---|---|---|---|
| Главная | ✓ | ✓ | директору — состав студии, итоги недели, отчёты; педагогу — его занятия сегодня; обоим — «Не отмечена посещаемость», блок «Кабинеты» |
| Расписание → День / Неделя | все занятия, фильтр по педагогу | свои занятия | список занятий, полоса недели, праздники |
| Расписание → Кабинеты | все занятия | свои подробно, чужие — «занято» | сетка «кабинет × время» на день (только кабинеты с занятиями или бронями), свободные окна, брони |
| Студия → Ученики (у педагога — «Ученики») | ✓ | ✓ («Мои / Все») | карточки детей с фото и контактом родителя; у ребёнка в списке — долг или аванс |
| Студия → Группы (у педагога — «Ученики» → «Группы») | ✓ | ✓ | составы групп |
| Студия → Педагоги | ✓ | — | педагоги и директора, приглашения, роль, имя, отключить / вернуть доступ |
| Студия → Кабинеты | ✓ | — | добавить, переименовать, выключить |
| Студия → «Часы и праздники» (кнопка в шапке) | ✓ | — | часы работы, рабочие дни, праздники |
| Касса → День | все оплаты и занятия дня | «Моя касса»: принятые им деньги и свои занятия | принято (наличные / перевод), начислено, не оплачено; занятия по педагогам с тем, кто из детей оплатил; доля педагога за день |
| Касса → Долги | все ученики | свои ученики | кто должен и у кого аванс, нажатие — лицевой счёт |
| Касса → Прайс | ✓ | — | тарифы, ставки с даты, особые условия педагогов; «по тарифам» и «по педагогам» |
| Карточка ученика → «Оплаты» | ✓ | своих учеников | баланс, выписка, «Принять оплату», «Написать родителю» |
| Отчёты (с Главной) | ✓ | — | нагрузка, посещаемость |
| Табло для холла (с Главной) | ✓ | ✓ | экран «сейчас / дальше» по кабинетам |

## 5. Сценарии использования (use cases)

Формат: **кто · где · шаги · результат · правила**.

### Вход и доступ

**UC-01. Войти в приложение** · директор, педагог · экран входа
1. Нажать «Продолжить с Google» и выбрать свой аккаунт — или ввести почту, «Получить код», ввести 6 цифр из письма, «Войти».
2. Приложение открывает Главную своей роли.
- Правила: войти в студию можно только с почтой из действующего приглашения; без приглашения — экран «Доступ ещё не открыт», с истёкшим — сообщение «Приглашение истекло»; отключённому — экран «Доступ отключён».

**UC-02. Пригласить педагога или директора** · директор · Студия → Педагоги
1. «Добавить» → роль (Педагог / Директор) → имя и почта Google-аккаунта → «Пригласить». Человек появляется в «Приглашены» со сроком «Действует до …».
2. Он входит с этой почтой → переходит в «Педагоги» или «Директора», ему выдаётся свой цвет в календаре.
- Альтернативы: «Отменить»; истёкшее — «Продлить» (ещё 30 дней).
- Правила: на почту того, кто уже в студии, приглашение не заводится — роль меняется в его строке (UC-02a).

**UC-02a. Изменить имя или роль** · директор · Студия → Педагоги → строка человека
1. Исправить имя и/или переключить роль «Педагог / Директор» → «Сохранить».
- Правила: свою роль меняет другой директор; последнего директора разжаловать или отключить нельзя.

**UC-02b. Отключить доступ** · директор · Студия → Педагоги → строка человека → «Отключить доступ»
1. Приложение показывает, сколько у человека занятий с выбранного дня и у скольких учеников он основной педагог.
2. Выбрать: «Передать» (кому; галочка «И учеников») · «Отменить» (серии останавливаются, будущие занятия без отметок убираются) · «Оставить» → «Отключить».
3. Если у нового педагога появились пересечения или остались занятия с отметками — приложение об этом скажет.
- Альтернатива: «Вернуть доступ» — всё как было до отключения (передачу не отменяет).
- Правила: прошлые занятия, посещаемость и оплаты остаются за ушедшим; удалить человека с занятиями нельзя ни из приложения, ни в Supabase.

### Справочники

**UC-03. Завести кабинеты** · директор · Студия → Кабинеты
1. «Добавить» → название → «Сохранить». Переименовать или «Выключить» — в строке кабинета.
- Выключенный кабинет не предлагается для новых занятий, но остаётся в истории.

**UC-04. Завести карточку ученика** · директор, педагог · Студия → Ученики (у педагога — «Ученики») → «Добавить» (или из формы занятия: «Добавить учеников» → «Новая карточка ученика»)
1. Фото: нажать на круг — откроется камера; или «Из галереи».
2. Имя, фамилия (обязательно); дата рождения (возраст считается сам); основной педагог (у педагога по умолчанию — он сам); ФИО и телефон родителя (WhatsApp): страна с флагом из списка и номер — вставленный номер с «+» сам выберет страну; «В студии с» (по умолчанию — сегодня); заметки; группы.
3. «Добавить ученика». «Карточка создана» проставляется сама.
- Правила: педагог правит потом только карточки своих учеников; передать ученика другому педагогу и убрать в архив — директор.

**UC-05. Связаться с родителем** · директор, педагог · карточка ученика / занятие с одним учеником / отчёт
1. В блоке «Родитель» нажать «WhatsApp» (открывается чат с родителем) или «Позвонить».
- Номер хранится с кодом страны (родители из разных стран). Старый номер без кода: в карточке подсказка «выберите страну», WhatsApp не откроется.
- На вкладке «Оплаты» — «Написать родителю» с готовым текстом: даты неоплаченных занятий и сумма долга (UC-23).

**UC-06. Собрать группу** · директор, педагог · Студия → Группы (у педагога — Ученики → Группы)
1. «Добавить» → название → отметить учеников галочками → «Создать группу».
2. Состав меняется в группе или в карточке ученика (поле «Группы»).
- Занятия группы следуют за её составом: добавили ребёнка в группу — он появился на её занятиях. Архив группы — директор.

### Расписание

**UC-07. Поставить занятие** · директор, педагог · Расписание → «Добавить» (или нажать на свободное место в «Кабинетах» → «Занятие»)
1. Состав: «Группа» (необязательно) и/или «Ученики» → «Добавить учеников» → галочки (свои ученики — сверху).
2. «Каждую неделю» (дни недели, «Начиная с», «До» — необязательно) или «Разовое» (дата).
3. Начало, длительность (30 / 45 / 60 / 90 или своя), кабинет; директор выбирает педагога.
4. «Тариф» подставляется сам: группа или несколько детей — групповой, один ребёнок — частный ближайшей длительности; под полем — цена и доля педагога. Директор может выбрать другой тариф того же вида, педагог видит, какой подставится.
5. «Добавить занятие». Если педагог или кабинет заняты — список пересечений и «Сохранить всё равно».
- Правила: серия создаёт занятия на 16 недель вперёд и досоздаёт дальше сама; педагог ставит занятия только себе; под неактивной кнопкой написано, чего не хватает.

**UC-08. Посмотреть своё расписание** · педагог (директор — всё или одного педагога) · Расписание
1. Полоса недели: точка — есть занятия, розовая дата — праздник; стрелки — листать недели, «Сегодня» — вернуться.
2. «День» — занятия выбранного дня; «Неделя» — вся неделя списком.
- На карточке занятия: время, кто, кабинет, сводка отметок («Были 4 из 5 · оплачено 3 из 4» — педагогу оплату видно у своих учеников), метки «не отмечено», «не состоялось», «перенесено», «отменено».

**UC-09. Перенести, отменить или удалить занятие** · владелец занятия, директор · карточка занятия
1. «Перенести это занятие» — новые дата, время, длительность, кабинет (меняется только это занятие).
2. «Отменить занятие» / «Вернуть занятие».
3. «Удалить занятие» — только разовое и без отметок.
- Проведённое (с отметками) занятие нельзя отменить.

**UC-10. Изменить серию** · владелец, директор · карточка занятия серии
1. «Изменить расписание серии» → «Изменить начиная с» → день недели, время, длительность, кабинет, тариф (директор), последний день.
2. «Остановить повторение» — это и следующие занятия серии удаляются, прошедшие остаются.
- Прошлое не переписывается; разовые переносы и отмены после выбранной даты сбрасываются.

**UC-11. Изменить состав занятия** · владелец, директор · карточка занятия → «Изменить состав»
1. Для серии выбрать «Только это занятие» или «Это и следующие».
2. Поменять группу и/или учеников → «Сохранить состав».
- Если у убираемого ребёнка уже есть отметка на этом занятии — предупреждение, отметка удалится. При «Это и следующие» отметки сохраняются.

### Посещаемость

**UC-12. Отметить посещаемость** · владелец занятия, директор · карточка занятия
1. Шапка карточки: справа от названия — педагог; ниже в два столбца: дата | время, кабинет | повтор («Каждую субботу»); строкой ниже — тариф и цена («Группа · 60 мин, 25 € с каждого пришедшего»; директор может поменять тариф нажатием на название).
2. У каждого ребёнка: имя, под ним долг или аванс; одна кнопка посещения, по кругу: пунктирная «Есть?» (ещё не отмечен) → «✓ Есть» → «✕ Нет» → снова «Есть?». Для группы — «Все пришли» / «Остальные пришли».
3. «Есть» сразу начисляет ребёнку цену занятия, педагогу — его долю. Рядом с отметкой — деньги: «✓ 25 €» — оплачено (в том числе авансом), «◐ 10 / 25 €» — частично, «Принять» — открыть приём оплаты (UC-22).
4. Если все отмечены «Нет» — под списком пояснение: никто не пришёл, занятие не состоялось и не идёт в нагрузку педагога.
- Старые отметки «опоздание» и «уважительная» (до 31.10.2026) показываются как «Есть» и «Нет»; в отчёте они видны отдельно.
- Правила: посещение — с дня занятия; деньги можно принять заранее — они лягут авансом. Хоть один «Есть» — занятие «проведено»; отметки есть, но все «Нет» — «не состоялось» (педагогу не засчитывается); прошло без отметок — «не отмечено». «Нет» и снятие отметки снимают начисления: не пришёл — бесплатно.

**UC-13. Не забыть отметить** · педагог, директор · Главная → «Не отмечена посещаемость»
1. Прошедшие занятия за 30 дней без отметок; нажатие открывает карточку занятия.

### Кабинеты

**UC-14. Найти свободный кабинет** · директор, педагог · Расписание → «Кабинеты» (или Главная → «Кабинеты по времени»)
1. День выбирается в полосе недели.
2. Над сеткой — «Свободны весь день: …»: кабинеты без занятий и броней в сетку не попадают. Нет ничего — сообщение вместо пустой сетки.
3. Сетка дня — только занятые в этот день кабинеты: пунктир «свободно 13:30–18:00»; чужие занятия у педагога — «занято».
4. Нажать на свободное место → «Занятие» или «Бронь кабинета»; в полностью свободный кабинет — кнопками «Добавить» / «Забронировать».
- Таблица «Загрузка кабинетов» (кабинеты × дни, % от часов работы) с 31.10.2026 убрана с экрана — расчёт остался в коде.

**UC-15. Забронировать кабинет без урока** · директор, педагог · «Кабинеты» → «Забронировать» или свободное место → «Бронь кабинета»
1. Кабинет; «Для чего» (Репетиция, Концерт, Мероприятие, Настройщик, Ремонт или своё); дата, начало, длительность; заметка.
2. Галочка «Снять бронь, если её не подтвердят» (по умолчанию включена; для настройщика или ремонта — снять).
3. «Забронировать». Пересечения с занятиями и бронями — предупреждение и «Забронировать всё равно».

**UC-16. Подтвердить или снять бронь** · все (подтвердить), автор и директор (снять) · бронь в сетке или табло
1. За 15 минут до начала и до 15 минут после — «Подтвердить — я в кабинете» (на табло — «Я здесь»).
2. Не подтвердили вовремя — бронь снимается сама, кабинет считается свободным.
3. «Снять бронь» — освобождает кабинет сразу.

**UC-17. Табло в холле** · любой аккаунт студии · Главная → «Табло для холла» (адрес `/board`)
1. Открыть на планшете или ТВ в холле — по каждому кабинету «занят / свободен», что идёт сейчас и до скольких, что дальше; часы и праздник дня.
- Обновляется каждую минуту, экран не гаснет; дети показаны как «Алиса М.»; «Выйти» — вернуться в приложение.

### Директор: студия и отчёты

**UC-18. Часы работы и праздники** · директор · «Студия» → «Часы и праздники» (или Главная → «Часы и праздники»)
1. «Часы работы»: открытие, закрытие, рабочие дни → «Сохранить часы» (по ним строится сетка кабинетов и свободные окна).
2. «Праздники»: год → «Добавить праздники РФ на год» или своя дата и название → «Добавить праздник»; удалить — корзина.
- Праздник только помечается: занятия и брони в этот день идут как обычно.

**UC-19. Нагрузка** · директор · Главная → «Отчёты» → «Нагрузка»
1. Неделя или месяц (стрелки, «Эта неделя / Этот месяц»): занятия и часы — проведено / не отмечено / впереди; «не состоялось» и «отменено» показаны отдельно и в часы не входят; по педагогам и кабинетам.
2. Нажатие на педагога — его неделя в расписании; на кабинет — сетка кабинетов.

**UC-20. Посещаемость** · директор · «Отчёты» → «Посещаемость»
1. Доля пришедших, разбивка по статусам, предупреждение о неотмеченных, строка по каждому ученику → его занятия с отметками и начисленной ценой.

### Касса и деньги учеников

**UC-21. Прайс и доли** · директор · «Касса» → «Прайс»
1. «Новый тариф»: «Группа» или «Частное», длительность, название (необязательно), цена с ребёнка, «Педагогу» и «Студии» — вписать можно любую часть, вторая посчитается сама; полоска раскладки и пример «Пришли 4 ребёнка: педагогу 60 €, студии 40 €»; «Действует с».
2. Изменить цену или долю — нажать на тариф, вписать новые и дату «Действует с»: занятия до этой даты — по прежней ставке, будущая ставка видна в карточке «с 15.11 — 28 €», её можно отменить. Внизу — история ставок. Ненужный тариф — «В архив».
3. Особые условия педагога: под тарифом «+ особые условия» (выбрать педагога) или вид «По педагогам» → строка тарифа. «Как у всех / Свои»: своя цена и/или своя доля, пустое поле — как у всех (поднимут общую цену — поднимется и здесь); с даты, с историей.
- Правила: меняет только директор; уже отмеченные занятия не пересчитываются; сначала особые условия педагога, потом общий тариф.

**UC-22. Принять оплату** · директор (у любого ученика), педагог (у детей своих занятий) · карточка занятия → «Принять» или карточка ученика → «Оплаты» → «Принять оплату»
1. Сверху — долг или аванс и какие занятия не оплачены.
2. «Получено»: вписать сумму или нажать «Весь долг · 75 €», «Долг + занятие», «1 занятие».
3. Дали больше долга — «Сдача 25 € / Оставить авансом»; способ — «Наличные / Перевод».
4. До кнопки видно, что будет: «✓ Закроет 19.10, 26.10», «◐ 02.11 — 10 из 25 €», «Аванс 25 €». «Принять 100 €».
5. После приёма 5 секунд можно нажать «Отменить» (без причины), потом шторка закрывается сама.
- Правила: деньги закрывают занятия по очереди, с самого старого; остаток — аванс, им закроются следующие занятия; записывается только оставленная сумма (сдача мимо кассы); в оплате запоминается, кто принял.

**UC-23. Лицевой счёт ученика** · директор, педагог (свои ученики) · карточка ученика → «Оплаты» (или «Касса» → «Долги» / «День» → ребёнок)
1. Баланс одним числом: «Долг 75 €» (красный), «Аванс 25 €» (зелёный, «хватит примерно на 1 занятие»), «0 €».
2. Выписка от новых к старым: занятия («оплачено», «◐ оплачено 10 € из 25 €», «не оплачено»), пропуски (бесплатно), оплаты с тем, кто принял; справа — сумма и баланс после неё.
3. «Принять оплату» (UC-22), «Написать родителю» — WhatsApp с датами неоплаченных занятий и суммой долга.
4. Ошиблись в оплате — нажать на неё → причина → «Отменить оплату»: строка остаётся зачёркнутой «отменена: …».
- Правила: оплаты не удаляются и не правятся; педагог отменяет свою оплату до конца дня (по часовому поясу студии), дальше — директор.

**UC-24. Касса дня** · директор, педагог («Моя касса») · «Касса» → «День»
1. День листается стрелками, «Сегодня» — вернуться.
2. Сверху: принято (из них наличными), начислено за занятия дня, не оплачено.
3. «Оплаты за день» (у педагога — «Принято мной»): время, ребёнок, способ, кто принял, сумма; отменённые зачёркнуты.
4. «Занятия» по педагогам с долей педагога за день: у каждого ребёнка «✓ 25 €», «◐ 10 из 25 €», «! долг 25 €», «пропуск · 0», «ждём отметку». Нажатие — лицевой счёт.

**UC-25. Долги и авансы** · директор (все), педагог (свои ученики) · «Касса» → «Долги» (или Главная → «Долги учеников»)
1. «Должны» — от самого большого долга, «Авансы» — от самого большого; итоги сверху.
2. Нажатие — лицевой счёт ученика (UC-23).

## 6. Пользовательские истории (user stories)

Формат: *Как ‹роль›, я хочу ‹действие›, чтобы ‹польза›.* — критерии приёмки.

### Директор

- **US-D1.** Как директор, я хочу пригласить педагога по почте, чтобы он сам вошёл и сразу оказался в студии.
  — Приглашение = имя + почта; вход с этой почтой создаёт профиль педагога; чужая почта доступа не получает.
- **US-D2.** Как директор, я хочу видеть расписание всей студии с фильтром по педагогу, чтобы понимать, кто и когда занят.
  — «Все педагоги» или один; цвет полоски = педагог.
- **US-D3.** Как директор, я хочу ставить и менять занятия любого педагога, чтобы планировать студию целиком.
  — Выбор педагога в форме; перенос и изменение серии с другим педагогом.
- **US-D4.** Как директор, я хочу видеть нагрузку педагогов и кабинетов за неделю и месяц, чтобы распределять часы.
  — Часы и занятия по состояниям; переход в расписание педагога и в сетку кабинетов.
- **US-D5.** Как директор, я хочу видеть долг или аванс каждого ребёнка и выписку его денег, чтобы не листать тетрадь назад.
  — «Касса» → «Долги»; лицевой счёт: баланс одним числом, выписка с тем, кто принял; деньги гасят занятия с самого старого.
- **US-D10.** Как директор, я хочу задать цену занятий и долю педагога (общую и особые условия педагога) с даты, чтобы доля считалась сама и прошлое не пересчитывалось.
  — Тарифы «группа / частное» с длительностью; «педагогу + студии = цена»; «Как у всех / Свои»; история ставок; изменения — с даты.
- **US-D11.** Как директор, я хочу видеть кассу дня — сколько принято, кем и кто из детей не оплатил, — чтобы закрывать день как страницу дневника.
  — «Касса» → «День»: принято (наличные), начислено, не оплачено; занятия по педагогам; отмена оплаты с причиной.
- **US-D6.** Как директор, я хочу задать часы работы и праздники студии, чтобы загрузка кабинетов считалась честно, а праздники были видны всем.
  — Часы и рабочие дни сохраняются; «праздники РФ на год» одной кнопкой; праздник не отменяет занятия.
- **US-D8.** Как директор, я хочу назначить второго директора и исправлять имена сотрудников, чтобы управлять студией не только в одиночку.
  — Роль «Директор» при приглашении или в строке человека; последний директор не может уйти, пока не назначен другой.
- **US-D9.** Как директор, я хочу отключить ушедшего педагога и сразу передать его занятия и учеников другому, чтобы расписание не держало кабинеты за человеком, которого нет.
  — Доступ закрывается сразу; «Передать / Отменить / Оставить»; история остаётся; предупреждение о пересечениях.
- **US-D7.** Как директор, я хочу убирать учеников и группы в архив и передавать ученика другому педагогу, чтобы справочник оставался актуальным без потери истории.
  — Архив — только у директора; история занятий и отметок сохраняется.

### Педагог

- **US-T1.** Как педагог, я хочу открыть приложение и сразу увидеть свои занятия на сегодня, чтобы не искать расписание.
  — Главная: «Сегодня» — только свои занятия.
- **US-T2.** Как педагог, я хочу поставить себе занятие с группой, отдельными учениками или группой и ещё учениками, разовое или на каждую неделю, чтобы расписание само повторялось.
  — Серия на 16 недель вперёд; предупреждение о пересечениях; занятие только на себя.
- **US-T3.** Как педагог, я хочу отметить посещаемость в одно касание, в том числе по каждому ребёнку группы, и сразу видеть, кто оплатил, чтобы журнал вёлся прямо на уроке.
  — у каждого ребёнка «Есть? → ✓ Есть → ✕ Нет» по кругу и деньги: «✓ 25 €» / «◐» / «Принять»; под именем — долг или аванс; «Все пришли»; посещение — с дня занятия; никто не пришёл — занятие «не состоялось».
- **US-T10.** Как педагог, я хочу принять деньги у ребёнка прямо на уроке и дать сдачу, чтобы родителю не нужно было искать директора.
  — «Принять»: быстрые суммы, что закроется, «сдача или аванс», наличные / перевод; деньги сразу видны директору; свою оплату можно отменить до конца дня.
- **US-T11.** Как педагог, я хочу видеть свою кассу — что я принял и свою долю за день, — чтобы вечером знать суммы заранее.
  — «Касса» → «День» («Моя касса»): принято мной, мои занятия и доля; «Долги» — мои ученики. Чужие деньги и выручка студии не видны.
- **US-T4.** Как педагог, я хочу видеть прошедшие занятия без отметок, чтобы ничего не забыть.
  — «Не отмечена посещаемость» на Главной за 30 дней.
- **US-T5.** Как педагог, я хочу сам заводить карточки учеников с фото и контактом родителя и править карточки своих учеников, чтобы не ждать директора.
  — Камера или галерея; основной педагог — я; чужие карточки — только просмотр.
- **US-T6.** Как педагог, я хочу одним нажатием написать родителю в WhatsApp или позвонить, чтобы быстро предупредить о переносе.
  — Кнопки в блоке «Родитель» ведут на телефон родителя.
- **US-T7.** Как педагог, я хочу сам собирать группы и менять состав своих занятий, чтобы занятия отражали реальный состав.
  — Состав группы → её занятия; «Только это занятие / Это и следующие».
- **US-T8.** Как педагог, я хочу видеть, где и когда свободен кабинет, не видя чужих подробностей, чтобы поставить занятие или репетицию.
  — Сетка кабинетов на день, свободные окна; чужие занятия — «занято».
- **US-T9.** Как педагог, я хочу забронировать кабинет под репетицию или концерт, чтобы его не заняли.
  — Бронь видна всем; снимается сама, если её не подтвердили через 15 минут после начала.

### Студия (общее)

- **US-S1.** Как сотрудник студии, я хочу видеть в холле табло «сейчас / дальше» по кабинетам, чтобы не заглядывать в двери и не звонить друг другу.
  — Обновляется само; экран не гаснет; подтверждение брони «Я здесь».
- **US-S2.** Как сотрудник студии, я хочу пользоваться приложением с телефона как обычным приложением, чтобы оно было под рукой.
  — Установка на главный экран; само обновляется.

## 7. Правила и ограничения

| Правило | Как работает |
|---|---|
| Пересечения | педагог и кабинет проверяются перед сохранением (и с бронями); предупреждают, но не запрещают |
| Серии | занятия создаются на 16 недель вперёд и досоздаются при открытии расписания |
| Изменение серии | «с даты»: прошлое не меняется, разовые переносы после даты сбрасываются |
| Посещение | отмечается с дня занятия; деньги можно принять когда угодно (до занятия — авансом) |
| «Проведено» | ставится само, когда хоть один ребёнок отмечен «Есть»; проведённое нельзя отменить |
| «Не состоялось» | отметки есть, но все «Нет»: в нагрузку и часы педагога не входит; пропуски детей остаются в посещаемости; отметить кого-то «Есть» — занятие снова «проведено» |
| Удаление | только разовое занятие без отметок; ученики и группы — архив, не удаление |
| «Не отмечено» и снятие брони | считаются по часам устройства |
| Бронь | снимается сама через 15 минут после начала без подтверждения (если включена галочка); перерывов между бронями и лимитов длительности нет |
| Праздник | только пометка; занятия и брони идут как обычно |
| Загрузка кабинета | % занятого времени (занятия + брони) от часов работы — считается в коде, но с 31.10.2026 на экране не показывается |
| Не проверяется | «двойная запись» ребёнка на два занятия одновременно |
| Код на почту | приходит педагогам после настройки почты студии (M6); до этого — вход через Google |
| Роли и доступ | меняет только директор; себе — нельзя; в студии всегда ≥ 1 действующий директор |
| Приглашение | 30 дней, продлевается; не на почту того, кто уже в студии; Gmail сравнивается без точек и «+хвоста» |
| Удаление сотрудника | нельзя, если у него есть занятия (иначе пропали бы посещаемость и оплаты) — только «Отключить доступ» |
| Начисления | «Есть» — ребёнку цена, педагогу доля по ставке на дату занятия; ставятся базой в момент отметки и больше не меняются (кроме смены тарифа или педагога у занятия); «Нет» и снятие отметки — без начислений |
| Тариф занятия | подставляется по составу (группа или несколько детей — групповой) и длительности; другой — только директор и только того же вида; тарифа на дату ещё нет — берётся самая ранняя ставка; тарифов нет вообще — «Есть» без цены, начислится, когда тариф появится |
| Доля педагога | за каждого пришедшего ребёнка; оплатил ли ребёнок — не важно; видят директор и сам педагог |
| Оплата | гасит неоплаченные занятия с самого старого, остаток — аванс; записывается только оставленная сумма; не правится и не удаляется — отмена с причиной (педагог — свою до конца дня, директор — любую) |
| Ученик с оплатами | удалить нельзя (записи кассы не теряются) — только архив |
| Валюта и время | суммы в евро; «до конца дня» — по часовому поясу студии (берётся с устройства директора) |

## 8. Словарь

| Термин | Значение |
|---|---|
| Серия | повторяющееся занятие: «каждый вторник в 15:00» |
| Состав | кто должен быть на занятии: ученики группы + отдельные ученики + все, у кого уже есть отметка |
| Основной педагог | педагог, за которым закреплён ученик; правит его карточку |
| Отметка | посещение «Есть» / «Нет» (в старых отметках ещё «опоздание» и «уважит.») |
| Тариф | вид занятия (группа / частное) и длительность; у него ставки с даты: цена с ребёнка и доля педагога |
| Особые условия | своя цена и/или доля конкретного педагога по тарифу; пусто — как у всех |
| Начисление | цена занятия ребёнку и доля педагогу, которые ставит отметка «Есть» |
| Баланс, долг, аванс | оплатил − начислено: меньше нуля — долг, больше — аванс (деньги вперёд) |
| Касса дня | страница «дневника» за день: принято, начислено, не оплачено, занятия по педагогам |
| Бронь | кабинет занят не уроком: репетиция, концерт, настройщик… |
| Свободное окно | промежуток от 30 минут без занятий и броней в часы работы |
| Табло | экран для холла «сейчас / дальше» по кабинетам |

## 9. Что дальше

Следующий модуль — **M11 «Расчёт с педагогами»**: баланс педагога (доля −
выплаты − взятые у детей наличные + сданное в кассу), «Доплатить» / «Сдать в
кассу», авансы, «Моя касса» с итогом, отчёты за месяц. Доля педагога и «кто
принял деньги» записываются уже сейчас.

Идеи следующих модулей (из исследования конкурентов, 26.10): заметки к уроку
и домашнее задание, шаблоны сообщений родителю в WhatsApp, зарплата
педагогов по ставкам, напоминания в Telegram, отработки, доступ для
родителей, абонементы, заявки и пробные уроки — см. [ROADMAP.md](../ROADMAP.md).
