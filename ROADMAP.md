# VoiceStage — дорожная карта

Pet-project: PWA для музыкальной студии (1 директор + 5 педагогов, ~30 детей,
индивидуальные и групповые занятия, несколько кабинетов).

**Формат работы:** один модуль = одна сессия (чат). В начале сессии Claude
читает этот файл и память, чтобы понять, где мы. В конце модуля — отмечает его
здесь как выполненный и фиксирует, что сделано.

Стек: React + TS + Vite (PWA) · Tailwind · Supabase (Postgres + Auth + RLS) ·
деплой на Vercel. Вход: Email OTP (код) через Resend SMTP.

---

## ✅ M0 — Фундамент (готово)
- Каркас проекта, PWA, Tailwind, клиент Supabase.
- Схема БД: студии, профили, кабинеты, ученики, группы, расписание, занятия,
  посещаемость (+ флаг оплаты `is_paid`, сумма `amount` скрыта).
- Вход без пароля (Email OTP) + доставка писем через Resend.
- Онбординг-механика: приглашения + триггер авто-привязки профиля при 1-м входе.
- Студия «VoiceStage» создана, `voicestage.io@gmail.com` — директор.

---

## ✅ M1 — Оболочка + Справочник «Педагоги и кабинеты» (директор) — готово
- Навигация по ролям (нижнее меню), каркас интерфейса, провайдер профиля,
  защита директорских маршрутов, экран «доступ не открыт».
- Педагоги: список профилей + приглашения, добавить (имя + email → приглашение),
  включить/отключить, отменить приглашение.
- Кабинеты: список, добавить / переименовать / выключить.
- Бонусом: кнопка входа «Продолжить с Google» (нужна разовая настройка
  Google-провайдера в Supabase + OAuth-клиента в Google Cloud).
- **Итог:** директор наполняет студию людьми и кабинетами.

## M2 — Справочник «Ученики и группы»
- Ученики: список, карточка (имя, контакт родителя, заметки), добавить/архив.
- Группы: создать, редактировать состав (добавить/убрать учеников).
- **Итог:** есть кого и в каком составе записывать на занятия.

## M3 — Расписание
- Создание занятия: разовое и **повторяющееся** (шаблон `lesson_series`).
- Генерация конкретных занятий (`sessions`) из шаблонов на период.
- Личный календарь педагога (день/неделя).
- Базовая проверка конфликтов кабинета и педагога.
- **Итог:** расписание полностью ведётся в приложении.

## M4 — Посещаемость + флаг оплаты
- Экран занятия: список детей (из ученика/группы), статус в один тап
  (был / не был / опоздал / уважит.).
- Флаг «оплачено» рядом с ребёнком (сумма пока скрыта).
- **Итог:** педагог отмечает посещаемость и факт оплаты.

## M5 — Обзор директора
- Нагрузка педагогов (часы/занятия за период).
- Занятость кабинетов — сетка «кабинет × время».
- Сводка посещаемости.
- **Итог:** директор видит всю картину загруженности.

## M6 — Публикация + доставка педагогам
- Деплой на Vercel: приложение по ссылке, ставится на телефон (нужен аккаунт
  Vercel + GitHub — пуш согласуем с пользователем заранее).
- Resend: подтверждение домена → код входа доходит всем педагогам, а не только
  директору. (Можно сделать в параллель раньше, если нужно тестировать вход
  педагогов до M6.)
- **Итог:** студия реально пользуется приложением на телефонах.
